AI provider · Text generationChoose a provider, its model, and the matching API key. The same model handles scripts, scene plans, SEO, and thumbnail copy.
OpenRouter model list contains free text models only.

Only free OpenRouter text models are listed. The key is stored in local app settings and sent from the backend to OpenRouter.

Model availability and rate limits follow your GroqCloud account. The key is stored locally and sent only to GroqCloud.

Stock visualsUse the closest Pexels or Pixabay clip, then a stock still; if neither is available, the app creates a simple graphic fallback without an image model.

Background music is generated procedurally; no local or cloud music model is used.

Hosted narrationVoiceovers use Microsoft Edge TTS online. No local speech model or offline voice fallback is used.

Narration requires an internet connection. If hosted TTS is unavailable, generation stops with an error rather than switching to a local voice model.

CPU video encodingFinal MP4s are encoded with the CPU-based H.264 libx264 encoder. No GPU encoder is used.
