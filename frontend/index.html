Script drafting · OpenRouterChoose a free text model for the first draft; Ollama then reviews and finalizes it locally.
OpenRouter models are loaded from its public catalog. Free model availability and account limits can change.

The API key stays in local app settings and is sent only from the backend to OpenRouter. Video titles and draft prompts go to OpenRouter; Ollama analyzes and rewrites the returned draft locally. The selected Ollama model must be enabled.

Visual generationCreatorFlow prefers the closest Pexels or Pixabay stock clip, then a stock still; local SDXL is used only if no usable stock media is found.

Pixabay’s official API supports image and video search, not music search. Background music continues to be generated locally.

Narration voiceChatterbox is the natural-sounding local AI voice; Edge TTS and the offline system voice remain available fallbacks.

For Windows, run .\backend\setup_chatterbox_windows.ps1 from PowerShell. It installs Chatterbox in a separate environment so it cannot change CreatorFlow’s pinned PyTorch stack. The first voiceover downloads Chatterbox model weights. If Chatterbox is not installed or fails, narration transparently falls back to Edge TTS.
